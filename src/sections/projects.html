DevATS — Multi-ATS Job Ingestion Platform

A high-throughput distributed crawler & developer-focused job board probing 600+ tech companies across Greenhouse, Lever, and Ashby concurrently without requiring API keys. Features strict IT-only job classification (isItJob), automated 45-day stale retention pruning, Ashby salary range parsing, Redis facet caching, and sub-millisecond PostgreSQL GIN index filtering.

  • Multi-ATS Slug Discovery: Heuristic slug generation stripping legal suffixes with concurrent 3-platform probing.
  • IT-Only Classifier Guard & Pruning: isItJob classifier rejects non-development roles at adapter boundary, with automated sweeping CLI scripts and endpoints.
  • 45-Day Stale Retention Lifecycle (ADR/SDD 0005): Automated soft-deletion of expired roles preventing dead posting resurrection.
  • Redis Facet Cache & Salary Parsing (ADR/SDD 0001/0004): Caches top 100 facet tags for instant slicing and parses numeric compensation bands.

AMAE — Financial Ledger & Operations Platform

A production-grade, server-side rendered (SSR) web application connecting financial sponsors with field missionaries across Brazil. Automates recurring financial adoptions, tracks mission-field coordinates with geocoding, generates on-the-fly financial receipt PDFs, and provides full bilingual internationalization (English default and Brazilian Portuguese).

  • Bilingual Internationalization (EN / PT-BR): Dynamic locale switching in navbar, localized Django model choices and form labels, with full Pytest test coverage.
  • Decoupled Django Domain Modules: Isolated apps (missions, finance, pages) following clean architecture.
  • Automated Adoption Ledger: Multi-relational income/expense transactions with dynamic calculation rules.
  • High-Fidelity Automated Tests: Comprehensive Pytest test suite covering domain validations, statement generation, and language switching.

Live Multi-Tenant Cluster

K3s GitOps & Observability — Multi-Service Kubernetes Platform

A high-availability production cloud-native platform hosting Gabriel's complete project ecosystem on a multi-tenant K3s Kubernetes cluster. Implements declarative GitOps continuous delivery with ArgoCD (automated syncing, self-healing, resource pruning), centralized multi-tenant log aggregation with Loki & Promtail, and real-time telemetry via Prometheus and a custom-engineered 'K3s Production Apps 360' Grafana dashboard.

  • Declarative GitOps with ArgoCD: Continuous delivery pipelines with self-healing, automated syncing, and immutable SHA-based image tracking across all namespaces.
  • Full-Stack Telemetry & 360 Dashboards: Prometheus scraping cluster and application metrics, feeding a custom-built Grafana 'K3s Production Apps 360' dashboard.
  • Centralized Multi-Tenant Logging: Promtail daemonsets streaming container logs into Loki for instant query debugging without SSH container access.
  • Automated Cluster Verification & Tag Pruning: Multi-arch CI builds with automated Docker Hub tag pruning routines (keeping latest + 3 tags) and host healthcheck verification suites.
