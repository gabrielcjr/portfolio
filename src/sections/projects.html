SentinelMCP — Autonomous Kubernetes SRE Agent & MCP Orchestrator

An autonomous Site Reliability Engineering (SRE) agent and Model Context Protocol (MCP) server engineered in Python 3.12 (FastAPI, AsyncIO) for Kubernetes self-healing. Integrates multi-model ReAct reasoning (Groq Cloud, Google Gemini) with automatic failover to a deterministic heuristic engine, executing guarded zero-downtime rolling restarts, horizontal scaling, and post-mortem Root Cause Analysis (RCA) reports.

  • ReAct SRE Diagnostic & Triage Loop: Multi-step autonomous investigation querying Jaeger APM error rates, diagnosing Kubernetes pod exit codes (OOMKilled/CrashLoop), and inspecting container stdout/stderr logs.
  • Blast-Radius Safety Guardrails & Cooldowns: Protects production workloads with strict hourly restart limits (max 3/hr), 120s cooldown periods, replica boundaries (1-10), and mandatory dry-run diff verification.
  • Multi-Provider LLM & Zero-Cost Heuristic Fallback: Hybrid AI orchestration supporting Groq (Qwen/Llama) and Gemini with seamless cascade to a rule-based Deterministic Runbook Engine when offline or rate-limited.
